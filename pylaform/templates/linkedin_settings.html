Getting Started:
  1. Visit Proxycurl to get an API key
  2. Sign up for their free tier (provides some free credits)
  3. Enter your API key in the form above
  4. Save your settings
  5. Go to LinkedIn Import to import your profile data

Note: Proxycurl provides limited free credits. Each profile import typically uses 1 credit.
